# Репетитор

Личное приложение для обучения программированию и математике. Агент сначала выясняет, что ты уже знаешь, строит план в виде графа зависимостей и ведёт по нему: предсказание → объяснение → проверка. Освоенное возвращается на интервальное повторение.

Можно учить отдельную тему или свой репозиторий: агент читает проект (только на чтение), составляет его карту и план «сверху вниз».

## Запуск

| Файл | Что делает |
| --- | --- |
| `start.cmd` | Запуск на этом компьютере: http://localhost:3000 |
| `start-lan.cmd` | То же, плюс доступ с телефона по Wi-Fi. В окне появятся адрес и пароль |
| `dev.cmd` | Режим разработки с горячей перезагрузкой |
| `install.cmd` | Установка зависимостей (после изменения `package.json`) |
| `npm.cmd` | npm с Node этого проекта, например `npm.cmd test` |

Первый запуск и запуск после изменения кода собирают приложение, это около минуты.

Проекту нужен Node.js 20.9 или новее. В папке `.node` лежит портативный Node 24, скрипты используют его; системный Node не затрагивается.

## Настройка моделей

Открой «Настройки» в приложении:

- **Anthropic** или **OpenRouter** — вставь API-ключ.
- **Свой сервер** — любой адрес, совместимый с OpenAI API (Ollama, LM Studio и т. п.). Модель должна поддерживать вызов инструментов.
- **Подписка Claude** (Pro или Max) — без API-ключа. Нужен установленный Claude Code с выполненным входом (`claude`, затем `/login`). Приложение запускает его в фоне под твоим аккаунтом; лимиты общие с Claude Code и claude.ai. Только для личного использования.
- **Основная модель** ведёт уроки, **быстрая** отвечает на боковые вопросы.

Ключи хранятся в `%USERPROFILE%\.tutor\secrets.json`, вне проекта.

## Где лежат данные

- `data/tutor.db` — база SQLite: темы, планы, сессии, ответы, расписание повторений.
- `data/lan-password.txt` — пароль для входа с телефона.

Папка `data` не попадает в git. Чтобы перенести прогресс, скопируй её.

## Как устроено

| Папка | Содержимое |
| --- | --- |
| `src/app` | Страницы и HTTP-маршруты (Next.js) |
| `src/components` | Интерфейс: карточки вопросов, редактор кода, граф плана |
| `src/server/agent` | Промпты, инструменты агента, цикл хода; `claude-code.ts` — уроки на подписке через Claude Code |
| `src/server/llm` | Провайдеры моделей: Anthropic, OpenAI-совместимые, тестовая заглушка |
| `src/server/repo` | Сканер репозитория и инструменты чтения |
| `src/server/mastery.ts` | Оценка освоения и интервалы повторения (FSRS) |
| `src/lib` | Общая логика: проверка плана, авто-оценка ответов, запуск кода |
| `public/*-worker.js` | Выполнение Python (Pyodide) и JavaScript в браузере |
| `tests` | Тесты логики и полного цикла урока на тестовой модели |

Промпты репетитора — в `src/server/agent/prompts.ts`. От них качество обучения зависит сильнее, чем от остального кода.

## Безопасность

- Сервер слушает только `127.0.0.1`. В режиме `start-lan.cmd` каждый запрос требует пароль.
- Код из задач выполняется в браузере, в изолированном воркере, и не имеет доступа к файлам компьютера.
- При обучении по репозиторию агент видит только файлы внутри указанной папки. Зависимости, сборки, бинарные файлы и секреты (`.env`, ключи, `secrets.*`) исключены. Прочитанные фрагменты отправляются выбранному провайдеру модели.

## Проверки


# Репетитор

Личное приложение для обучения программированию и математике. Агент сначала выясняет, что ты уже знаешь, строит план в виде графа зависимостей и ведёт по нему: предсказание → объяснение → проверка. Освоенное возвращается на интервальное повторение.

Можно учить отдельную тему или свой репозиторий: агент читает проект (только на чтение), составляет его карту и план «сверху вниз».

## Запуск

**Linux (и macOS):** запусти `./start.sh`, откроется меню:

**Windows:** дважды щёлкни `start.cmd`, откроется то же меню:

1. Запустить и открыть в браузере (http://localhost:3000)
2. Запустить с доступом с телефона по Wi-Fi. В окне появятся адрес и пароль
3. Режим разработки с горячей перезагрузкой
4. Тестовая модель: без ключа и без расходов
5. Пересобрать и запустить
6. Установить или обновить зависимости
7. Прогнать тесты
8. Создать ярлык «Репетитор» на рабочем столе (и в меню приложений на Linux): он сразу запускает приложение

Без меню: `./start.sh start|lan|dev|mock|rebuild|install|test|shortcut` (на Windows — `start.cmd ...`). Если репетитор уже запущен, повторный запуск просто откроет его в браузере.

Файлы `start-lan.sh`, `dev.sh` (и `start-lan.cmd`, `dev.cmd` на Windows) вызывают соответствующий пункт меню. `./npm.sh` (и `npm.cmd`) — это npm с Node этого проекта, например `./npm.sh test`.

Первый запуск и запуск после изменения кода собирают приложение, это около минуты. Если зависимости не установлены, они ставятся сами.

Для «Изменений» и ссылок на GitHub нужен установленный Git. Проекту нужен Node.js 20.9 или новее (рекомендуется 22+). Если в папке `.node` лежит портативный Node, скрипты используют его, иначе берут установленный в системе.

## Что умеет

- **Семестр** (`/semester`): полный курс до конца, чтобы знать предмет целиком.
  - **Откуда программа.** Тема и уровень («матанализ, полный курс», «дискретка, продвинутый»), один или несколько файлов с ролями (основной учебник, задачник, конспект лекций, дополнительно) — или всё вместе. Тема задаёт охват и глубину, книги — содержание; чего в книгах нет, модель добавляет и помечает «не из твоих материалов». Без книг она советует учебники.
  - **Длинные книги** (PDF до 100 МБ) хранятся постранично и делятся на разделы: по закладкам PDF, по печатному оглавлению (модель читает его и сопоставляет с настоящими страницами), по заголовкам в тексте, по началу каждой страницы или просто кусками страниц. В урок попадают только нужные страницы: у репетитора есть инструменты «прочитать страницы» и «найти в книге» (полнотекстовый поиск), он ссылается на страницы и берёт упражнения из книги.
  - **Программа** — части → модули → разделы с привязкой к страницам. Разделы основного учебника, которые модель пропустила, добавляются сами. Объём честно сравнивается со временем (недели × часы); большой курс можно урезать по частям. Перед началом программу можно править: переименовать, переставить, убрать, добавить разделы прямо из оглавления книги.
  - **Уровни**: базовый, стандартный, продвинутый — глубина объяснений и задач и порог контрольной (80, 85, 90%).
  - **Модули по очереди.** Идеи модуля составляются по тексту книги перед его началом; репетитор не может их убрать или счесть известными. Модуль закрывается только контрольной; её можно сдать и досрочно, без уроков. Не сдал — пересдача через 20 часов, ошибки уходят в работу над ошибками.
  - **Нулевой модуль и входной тест**: что курс предполагает известным; слабое подтягивается до первого модуля.
  - **Промежуточный и итоговый экзамены** накопительные: вопросы из всех сданных модулей. Итоговый завершает семестр, дальше знания держит повторение.
  - **«Знаю надёжно»**: идея изучена, проверена, объяснена своими словами и держится в памяти три недели и дольше.
  - **Календарь** по неделям: темп («в графике», «отстаёшь»), сколько часов нужно, чтобы успеть, и что делать сегодня — это видно и на главной.
  - **Домашние задания** раз в неделю: одна содержательная задача по модулям недели, проверка по критериям с разбором.
  - **Ведомость**: все работы и итог по лучшим попыткам (контрольные 40%, домашние 20%, промежуточный 15%, итоговый 25%) — в процентах и оценкой 2–5.
  - Книгу можно добавить и в идущий семестр: она разложится по разделам программы, и уроки начнут её читать.
  - **Сканы** (PDF без текстового слоя) распознаются на сервере без модели — Tesseract в WebAssembly, русский и английский, работает офлайн и на слабом компьютере (примерно 1–5 секунд на страницу, в фоне, с продолжением после перезапуска). Формулы со сканов распознаются плохо: их видно на самой странице в просмотрщике.
  - **Просмотр страниц** (`/book/<id>`): настоящая страница PDF рисуется в браузере, с оглавлением и масштабом; «стр. 142» в уроке модуля открывает книгу рядом с уроком.
  - **Пауза и перенос**: на паузе календарь стоит, при возобновлении сроки сдвигаются; календарь можно сдвинуть на дни и изменить число недель.
  - **Апелляция** домашки (один раз, оценка может только вырасти) и **пересдача на лучшую оценку** контрольных и экзаменов.
  - **Устный экзамен** (`/oral?topic=<id>`, кнопка у темы и модуля): вопросы читаются вслух, отвечаешь голосом (Chrome, Edge, Safari) или текстом; оценка по каждой идее, хорошо объяснённое засчитывается как «объяснено».
  - **Карта курса**: все идеи семестра цветом по ступеням освоения, слабые места и что пора повторить.
- **Фото решения** в свободных ответах, задачах с решением и домашках: снимок переписывается в текст с формулами LaTeX, и ты проверяешь его перед отправкой. Читает основная модель, если она видит изображения (Claude, GPT, Gemini — на любом подключении); иначе — локальное распознавание, которое хорошо читает печатное и плохо рукопись.
- **Быстрый экскурс** (`/brief`): краткая карта темы, файлов или репозитория по тезисам — суть, главное, как работает, пример, ловушки, словарь. Глубина 1, 5 (по умолчанию) или 15 минут чтения. Любой пункт раскрывается подробнее по клику (раскрытое сохраняется). «Учить это подробно» превращает экскурс в тему, и репетитор начинает с учётом прочитанного; для репозитория экскурс становится картой проекта.
- **Источники экскурса и материалов темы:** тема, файлы (PDF — в том числе сканы и схемы/таблицы через vision-модель, Word `.docx`, PowerPoint `.pptx`, Jupyter `.ipynb`, изображения `.png`/`.jpg`/`.webp`, код, текст, Markdown; до 250 тыс. символов в урок), ссылка на статью или PDF, папка проекта или ссылка на публичный репозиторий GitHub (скачивается в `data/repos`), а также **«Изменения»** — что поменялось в проекте с прошлого экскурса (по git).
- **Карточки:** из экскурса или конспекта модель делает вопросы, они сразу попадают в «Повторение на сегодня» и дальше идут по своему расписанию. Список и удаление — во вкладке темы «Карточки».
- **Вопрос к проекту** (`/ask`): чат по коду папки или репозитория GitHub, ответы со ссылками `файл:строка`. Для каждого вопроса читаются нужные файлы.
- **Экзамен** по теме: 10–25 вопросов по всем идеям плана, таймер, без подсказок; в конце результат по каждой идее, ошибки уходят в «Работу над ошибками». Если своих вопросов мало, модель дописывает новые.
- **Цель на день** (по умолчанию 10 ответов, меняется в «Настройках»): кольцо на главной и в статистике.
- **Поиск по всему** в `Ctrl+K`: темы, экскурсы, конспекты, вопросы, карточки, парковка, разговоры о проектах.
- **Экспорт в Anki:** вкладка темы «Карточки» → «Экспорт в Anki», затем в Anki «Файл → Импорт».
- **Подготовка к дате** (`/plan`): дата экзамена и темы — план по дням: что изучить, ежедневное повторение, пробные экзамены, день на ошибки. Пересчитывается сам, если отстаёшь или обгоняешь. «План на сегодня» — на главной.
- **Объясни своими словами** (кнопка на странице темы): объясняешь идею, как будто учишь другого; репетитор находит пробелы и ошибки и задаёт уточняющий вопрос (до 4 раундов).
- **Теория по идеям:** объяснения репетитора из уроков (шаги теории, «Объясни подробнее», разборы) сохраняются за идеей плана, когда ты отвечаешь на вопрос по ней. Вкладка темы «Теория» или «Теория по идее» на карте. Конспект строится и по ней.
- **Отметки на шагах:** под каждым объяснением и вопросом — «Непонятно», «Длинно», «Ошибка» (с комментарием). Репетитор получает отметку со следующим действием и подстраивается; журнал отметок — в «Статистике».
- **Проверка вычислений:** перед тем как показать выкладку или эталон, репетитор считает на Python (sympy, numpy) на сервере — Pyodide в отдельном потоке, до 20 секунд на запуск; ученик этого не видит. Пакеты скачиваются один раз в `data/pyodide-cache`.
- **Графики функций:** блок ```` ```plot ```` в уроках, экскурсах и ответах о проекте — `y = sin(x) | подпись`, `x = 2`, `point 1, 2 | A`, `x: -5..5`; при наведении видны значения. Без сторонних библиотек.
- **Редактор формул:** кнопка «Формула» у свободных и математических ответов и в домашних заданиях — визуальный ввод (MathLive) с кнопками дробей, интегралов, пределов; формула вставляется в ответ как `$…$`.
- **Схемы:** репетитор, экскурс, конспект и ответы о проекте могут рисовать схемы Mermaid — они отображаются как диаграммы.
- **Песочница** (`/sandbox`): Python, JavaScript и SQL (настоящий PostgreSQL на WebAssembly — PGlite) в браузере. Несколько файлов во вкладках (`import helpers` / `require("./helpers")` / `\i schema.sql`), ввод для `input()`, вывод по ходу выполнения, остановка, графики matplotlib (numpy и matplotlib подгружаются при первом импорте), строка с ошибкой отмечается в редакторе, «Мои программы» (Ctrl+S), открыть и скачать файлы, «Спросить репетитора» с кодом и ошибкой. У блоков кода в уроках и экскурсах есть кнопка «В песочницу».
- **Редактор кода в уроках:** автодополнение, подсветка парных скобок, поиск (Ctrl+F), комментарий (Ctrl+/), строка с ошибкой после запуска, «Сбросить» к заготовке, режим во весь экран, размер шрифта и перенос строк (общие с песочницей).
- **Видео:** в экскурсе «Ссылка или видео» можно дать ссылку на YouTube — берутся субтитры, в экскурсе ссылки на моменты видео. Если YouTube не отдаёт субтитры приложению, скачай `.srt`/`.vtt` или скопируй «Текст видео» и приложи файлом: субтитры читаются с метками времени.
- **Разбор кода** (режим экскурса): вставь код или приложи файлы — что хорошо, ошибки и риски со ссылками на строки, как улучшить, чему научиться. Из разбора можно сделать карточки или тему.
- **Уроки с репетитором:** диагностика, план в виде графа, теория и вопросы, итог сессии. Новая идея начинается с теории (зачем, точная формулировка, интуиция, разобранный пример, частые ошибки, вывод), знакомая — с попытки ответить самому. Длинная теория идёт по экранам с кнопкой «Дальше»; «Объясни подробнее» разбирает текущую идею глубже, в том числе когда открыт вопрос (он вернётся). Сколько теории давать — «Настройки» → «Теория в уроках»: кратко, обычно, подробно. В семестре разделы излагаются полно, по книге.
- **Повторение на сегодня** (`/review`): вопросы из прошлых уроков по всем идеям, которые пора освежить, сразу по всем темам. Работает без модели, бесплатно; каждый ответ сдвигает следующее повторение (FSRS). Свободные ответы сверяешь с эталоном сам.
- **Работа над ошибками** (`/mistakes`): неверно решённые вопросы. Верный ответ убирает ошибку из списка, непонятную можно разобрать с репетитором.
- **Статистика** (`/stats`): календарь активности как на GitHub, серия дней подряд, точность по темам, калибровка уверенности, расходы на модели по дням.
- **Конспект** темы: шпаргалка, которую репетитор пишет по плану, итогам уроков и твоим ошибкам. Можно скопировать или скачать .md.
- **Парковка** отложенных мыслей как список задач: отметить, разобрать на уроке, сделать отдельной темой, удалить.
- **Клавиши:** `1`–`9` выбрать вариант, `Ctrl+Enter` ответить, `H` подсказка, `Enter` дальше, `Ctrl+K` палитра команд, `Ctrl+B` проводник.
- **Тема оформления:** светлая, тёмная или как в системе (кнопка на левой панели, Ctrl+K или «Настройки»).
- **Вид:** минималистичный (по умолчанию: одна спокойная страница, основные разделы слева, остальное — через Ctrl+K, проводник скрыт) или подробный, как в редакторе кода (все разделы на панели, проводник, вкладка, строка состояния). Переключается в «Настройках» → «Оформление» или через Ctrl+K.
- **Дневной лимит расходов** в «Настройках»: при превышении уроки ставятся на паузу до полуночи.
- **Резервные копии:** скачать и восстановить в «Настройках» → «Данные». При каждом запуске через `start.cmd` база копируется в `data/backups` (хранятся последние пять); перед восстановлением текущее состояние тоже сохраняется туда.

## Настройка моделей

Открой «Настройки» в приложении:

- **Anthropic** или **OpenRouter** — вставь API-ключ.
- **Свой сервер** — любой адрес, совместимый с OpenAI API (Ollama, LM Studio и т. п.). Модель должна поддерживать вызов инструментов.
- **Подписка Claude** (Pro или Max) — без API-ключа. Нужен установленный Claude Code с выполненным входом (`claude`, затем `/login`). Приложение запускает его в фоне под твоим аккаунтом; лимиты общие с Claude Code и claude.ai. Только для личного использования.
- **Подписка ChatGPT** (Plus, Pro, Business…) — без API-ключа, через Codex: `npm install -g @openai/codex`, затем `codex login` → «Sign in with ChatGPT». Модель `default` — та, что в Codex по умолчанию.
- **Аккаунт Google (Antigravity)** — без API-ключа, через Antigravity CLI (`agy`, ставится с antigravity.google): запусти `agy` и войди через Google. Модель `default` — та, что выбрана в agy (`/model`); «Загрузить список моделей» показывает остальные. Заменил Gemini CLI, который перестал работать: сохранённые настройки Gemini CLI переключаются на Antigravity сами.
- **GitHub Copilot** (любой план, включая бесплатный) — без API-ключа: «Настройки» → «GitHub Copilot» → «Войти через GitHub», ввести показанный код на github.com. Дальше приложение обращается к API Copilot напрямую (совместим с OpenAI, настоящие вызовы инструментов и фото). Это вход плагинов Copilot для редакторов, GitHub не описывает его для сторонних программ — только для личного использования.
- ChatGPT и Antigravity работают так: на каждый шаг приложение запускает программу в пустой папке `data/codex` или `data/antigravity`. Codex запускается без своих инструментов и с системным промптом приложения. У Antigravity системный промпт не подменяется, поэтому инструкции урока идут в начале сообщения, а его инструменты в неинтерактивном режиме не получают разрешения. Вызовы инструментов урока модель пишет блоками `<tool_call>{…}</tool_call>`, приложение их разбирает (`src/server/llm/text-tools.ts`). Путь к программе можно задать через `TUTOR_CODEX_PATH` и `TUTOR_AGY_PATH`.
- **Основная модель** ведёт уроки, **быстрая** отвечает на боковые вопросы.

Ключи хранятся в `~/.tutor/secrets.json` (на Windows — `%USERPROFILE%\.tutor\secrets.json`), вне проекта.

## Где лежат данные

- `data/tutor.db` — база SQLite: темы, планы, сессии, ответы, расписание повторений, семестры и страницы их книг.
- `data/books` — исходные файлы книг семестров (для просмотра страниц). В резервную копию базы они не входят: после восстановления уроки и поиск работают по тексту из базы, а просмотрщик показывает текст страницы. Чтобы сохранить и сами PDF, копируй всю папку `data`.
- `data/ocr-lang` — языковые модели распознавания, копируются из пакетов при первом скане.
- `data/lan-password.txt` — пароль для входа с телефона.

Папка `data` не попадает в git. Чтобы перенести прогресс, скопируй её.

## Как устроено

| Папка | Содержимое |
| --- | --- |
| `src/app` | Страницы и HTTP-маршруты (Next.js) |
| `src/components` | Интерфейс: карточки вопросов, редактор кода, граф плана |
| `src/server/semester` | Семестр: программа, модули и экзамены, календарь, домашние задания; книги — `books.ts` (оглавление) и `book-read.ts` (чтение и поиск) |
| `src/server/agent` | Промпты, инструменты агента, цикл хода; `claude-code.ts` — уроки на подписке через Claude Code |
| `src/server/llm` | Провайдеры моделей: Anthropic, OpenAI-совместимые (OpenRouter, свой сервер, `copilot.ts`), Codex и Antigravity через их программы (`cli.ts`), тестовая заглушка |
| `src/server/repo` | Сканер репозитория и инструменты чтения |
| `src/server/mastery.ts` | Оценка освоения и интервалы повторения (FSRS) |
| `src/lib` | Общая логика: проверка плана, авто-оценка ответов, запуск кода |
| `public/*-worker.js` | Выполнение Python (Pyodide) и JavaScript в браузере |
| `tests` | Тесты логики и полного цикла урока на тестовой модели |

Промпты репетитора — в `src/server/agent/prompts.ts`. От них качество обучения зависит сильнее, чем от остального кода.

## Безопасность

- Сервер слушает только `127.0.0.1`. В режиме `start-lan.sh` / `start-lan.cmd` каждый запрос требует пароль.
- Код из задач выполняется в браузере, в изолированном воркере, и не имеет доступа к файлам компьютера.
- При обучении по репозиторию агент видит только файлы внутри указанной папки. Зависимости, сборки, бинарные файлы и секреты (`.env`, ключи, `secrets.*`) исключены. Прочитанные фрагменты отправляются выбранному провайдеру модели.

## Проверки

```
./npm.sh test
./npm.sh run typecheck
./npm.sh run lint
```

(На Windows используй `npm.cmd` вместо `./npm.sh`.)

Тесты интерфейса (Playwright, запускают приложение на порту 3199 с тестовой моделью и временной папкой данных, используют установленный Chrome):

```
./npm.sh run test:e2e
```

`TUTOR_MOCK=1 ./start.sh start` (на Windows — `set TUTOR_MOCK=1`) включает тестовую модель-заглушку: приложение работает без ключа и без расходов.
